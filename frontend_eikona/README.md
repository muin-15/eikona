# Frontend
Frontend of Eikona is combination of React + Vite + TypeScript + Tailwind + Vanilla js ,which results in Modern Frontend for Eikona.
---

## Project Structure

```
frontend_eikona/
├─ src/
│  ├─ assets
│  ├─ index.css
│  ├─ main.tsx
│  ├─ App.tsx
│  └─ App.css
├─ public/
│  ├─ user-guide.html
│  └─ userguide.css
├─ index.html
├─ Processing_Images/
├─ package.json
├─ vite.config.js
└─ README.md
```

---

## Installation

### Clone Repository

```bash
git clone <https://github.com/muin-15/eikona.git>
cd eikona/backend_eikona
```

Install dependencies

```
npm install
```

Start Development Server

```
npm run dev
```

---

## Build

```bash
npm run build
```

Preview Production Build

```bash
npm run preview
```
