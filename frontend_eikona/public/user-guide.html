EIKONA Guide

Eikona is a powerful web-basd image processing platform designed to make advanced image editing,enhancement,and computer vision techniques.Eikona provides wide range of operations;image transformations,geometric operations,filtering restoration,segmentation,object detection,and color analysis.

Though Eikona provides 99% success rate it can be falsy at sometimes.To recover from this the four sections of the Guide stands in a priority format.The Guide Section provides the proper way to use the web-app.It is created to provide flexibility to users.

Loading Buffers
Solution 1: Wait till 2-5 mins because some operations like Face detection and Object detection consumes a lot of time.
Solution 2: Even after this if the loading didn't stop then refresh the page.
Solution 3: If nothing makes the result then contact to support.
Upload an Image
As you hover the operation box it will change color to green.You can click anywhere in the green region to upload an image.
Upload two Images
For two Images the first image will be taken as the method given below,for second image you need to click in the White box.
Even if the sizes/format of the images is different the operations are taken place successfully.

Format Error
We support only 5 formats (.jpg/.jpeg , .png , .webp , .bmp , .tiff)
TIFF Error
Solution: Somtimes tiff could not work due difference in number of channels
Solution: Even if users tries somehow to get tiff,it will not actually be a tiff but a png by default settings.
Resize problem
Solution: Sometimes exclusive functions like detection cannot figure out the object,this could be because the small size of the image or that image could be a screenshot or AI generated.At times like this you should scale the image up/down based on need.
Network Error
Solution: Network Errors are pretty common ,this may happen due to the network traffic,site under-construction or improper user connection to the website.To recover from this first we checkout for connection then we need to wait for sometime then apply again.
